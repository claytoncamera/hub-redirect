# hub.claytoncamera.com

Short address for Clayton's command-center hub. It forwards to the NOC `/hub` page on the Mac mini, which is private: Tailscale Serve, tailnet devices only. This repo holds only the redirect page; the hub itself and its list of consoles live in the private `claytron-noc` repo (`hub.json`). DNS: `hub` CNAME → `claytoncamera.github.io` at GoDaddy.
